动作与神情观察

prototype

用浏览器本地的 MediaPipe 模型看手势、姿态、微笑和头部朝向。视频不会离开你的电脑。结果只用于观察，不进正式评分。

把演讲视频拖到这里，或

mp4 / mov / webm · 建议 3 分钟内 · 本地处理

先选择视频。

身体动作

–检测率能稳定找到人体、且人物够大的帧占比
–手势幅度手腕移动速度，单位：肩宽/秒
–手势次数明显手腕动作，次/分钟
–身体晃动肩中点移动速度，单位：肩宽/秒
–前后/侧向倾斜肩中点相对髋中点的偏移，% 肩宽
–手高于肩至少一只手高于肩线的帧占比
–肩线倾斜两肩连线相对水平的角度

面部与头部

–检测率能稳定找到人脸、且脸够大的帧占比
–微笑强度0–100，来自嘴部 blendshape
–微笑占比微笑强度超过 0.25 的帧占比
–抬眉强度0–100，眉毛上扬的程度
–张嘴程度0–100，说话时通常会升高
–眨眼频率次/分钟；采样率低，只作参考
–头部左右偏移鼻子相对两眼中点的偏移，% 眼距
–头部俯仰偏移相对本人中位姿态的偏移，% 脸高
–头部侧倾两眼角连线的倾斜角，度
–朝前占比头左右/俯仰/侧倾都较小的帧占比
–表情变化微笑强度的标准差，越大越有起伏

采样帧

这是最后一个采样帧。蓝线是肩、肘、腕、髋；粉线是脸轮廓、眼睛和嘴。

怎么读

  • 这些是观察指标，不是分数。单个指标不能判断演讲好坏。
  • 显示 – 表示没有足够数据，不等于 0：人物太小、手腕/髋部不在画面、或脸太小都会这样。先看上面的警告。
  • “手势幅度”是手腕移动速度除以肩宽，抵消了人和镜头远近的差异；它不区分紧张的小抖和有力的手势。
  • “头部左右偏移”用鼻子相对两眼中点的位置估计，不是精确角度；镜头角度和镜头畸变会影响它。
  • “朝前占比”是相对本人中位姿态的稳定程度，不是眼动仪，也不能证明在看镜头。
  • 表情受文化、个人风格和疲劳影响；不要用微笑多少来判断真诚。
  • 采样率约 1–2 帧/秒，快速手势和眨眼会被漏掉；这是原型，不是测量仪。
